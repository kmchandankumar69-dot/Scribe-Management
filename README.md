\# Scribe Management System



A web-based management system for coordinating visually impaired persons, volunteers, examinations, coordinators, and feedback.



\## Features



\- Volunteer management

\- Visually impaired person management

\- Examination management

\- Coordinator management

\- Feedback management

\- Add and delete records

\- MySQL database integration

\- React frontend

\- Node.js/Express backend



\## Technology Stack



\### Frontend

\- React

\- JavaScript

\- HTML/CSS



\### Backend

\- Node.js

\- Express.js

\- MySQL2

\- dotenv

\- CORS



\### Database

\- MySQL
